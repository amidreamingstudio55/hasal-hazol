# הסל הזול – צור הדסה

מחשבון סל קניות שמשווה מחירים בין רשתות השיווק שמשרתות את צור הדסה, לפי קובצי המחירים הרשמיים שהרשתות מפרסמות לפי חוק המזון.

- `scripts/update_prices.py` – מוריד כל בוקר את קובצי המחירים והמבצעים ובונה את `docs/catalog.json`.
- `.github/workflows/update.yml` – משימה יומית שמריצה את הסקריפט ומפרסמת את האתר.
- `docs/index.html` – המחשבון.

המחירים שייכים לרשתות שפרסמו אותם. המחיר בקופה עשוי להשתנות.

## עותקים מישראל (data/local)
קרפור, ויקטורי ומחסני השוק לא עונות לשרתים של GitHub בחו"ל. לכן משימה יומית מורידה את הקבצים שלהן ממחשב בישראל, מפענחת אותם עם
`python scripts/update_prices.py --local <קוד רשת> PriceFull.gz PromoFull.gz`
ושומרת את התוצאה ב־data/local. העדכון של הבוקר משתמש בעותק הזה אם הוא לא ישן מ־3 ימים.
